# 02 · 逐屏规格（S01 – S14）

> 每条规格都必须能回答四件事：**它长什么样**、**它有哪几个状态**、**在它上面能做什么**、**做完怎么判断合格**。
> 组件用 `Cxx` 引用 [03-组件契约.md](03-组件契约.md)；基准值（字号/圆角/间距/颜色）用 `V1–V13` 引用 [01-范围与基准.md](01-范围与基准.md) §7。

**通用约定**

- 尺寸单位：px。视口基准 1440×900；最小支持 1280×800。
- 布局：左栏 240（可收至 0）/ 主区自适应 / 右栏 360（可收至 0）。收合动画 160ms。
- 状态词固定为：`默认` `空` `加载` `悬停` `选中` `禁用` `错误`；屏幕规格只列它真正需要的状态。
- 键盘：`⌘` 在 Windows 上等价 `Ctrl`；规格写 `⌘`，实现两者都认。
- 任何屏都不允许出现页面级跳转；一切切换发生在主区域内（tab 或右栏）。

## S01 · 今日（落点）

**目的**：时刻 C 的入口，同时替时刻 B 回答"我该学什么"。用户打开应用第一眼看到的不是空白，而是"我在学什么、下一步做什么"。

**进入方式**：启动默认落点；左栏「今日」；`⌘1`。

**布局**
```
┌ 左栏 240 ─┬──────── 主区（最大 760 居中） ────────┬ 右栏 360（可收）┐
│ 应用区    │  ① 主题与路径条（C40）                │ ⑤ 今日复习队列  │
│ 标签区    │  ② 继续上次（最近 2 块板，大卡预览）  │   （C42/C43）   │
│           │  ③ 今日新增（3 张最新卡）            │                 │
│           │  ④ 本周进度（C47 + 一行文字）        │                 │
└───────────┴───────────────────────────────────────┴─────────────────┘
```

**元素**：C02 C03 C05 C40 C47 C11 C42 C43 C65 C66

**状态**
- `默认`：四个区块按①②③④自上而下，间距 32；右栏展开显示复习队列。
- `空`（新用户/新主题无内容）：①显示路径第 1 阶 + 一句引导（"把第一份材料拖进来"），②③隐藏，④显示 0/0 但文案为"从第一张卡开始"。
- `加载`：②③用 C66 骨架，不显示空态。
- `零复习`：右栏改为一句"今天没有要复习的" + 一个"随便翻一张"入口（不允许空白）。

**主要交互**

| 动作 | 反馈 | 键盘 |
| --- | --- | --- |
| 点 ② 的板预览 | 打开该白板 tab（保留上次视口位置） | `Enter` |
| 点 ③ 的卡 | 右侧以引用方式打开卡（不新开 tab） | — |
| 拖入文件到 ② 区域 | 整区高亮 + 落点为"新板/现有板"二选一 | — |
| 点 ⑤ 的"开始复习" | 进入 S06（同一 tab 内切换，不跳页） | `R` |
| 悬停 ① 的任一阶 | 显示该阶的 3 条判据 | — |

**验收**
- [ ] 首次进入 5 秒后，用户能说出"我在学什么""接下来做什么"（≥ 4/5）。
- [ ] 四区块在 1280 宽下不出现横向滚动，②的预览图不被裁成半张卡。
- [ ] 无复习时仍有可点的"下一步"，不出现空白面板。
- [ ] 从本屏点进白板后返回，②的预览顺序不变（不因访问而重排）。

**因果**：若落点是空白画布，用户在 5 秒内收不到任何"下一步"信号（K1）。

## S02 · 白板画布（核心屏）

**目的**：时刻 B 的主战场——把材料与想法摆成结构。全应用最重要的屏，手感决定产品成立与否。

**进入方式**：左栏白板列表 / 标签条 / S01 的 ② / 卡片信息里的"出现在这些板" / `⌘P` 后选择。

**布局（三层）**
```
┌ 左栏 240 ┬─ 标签条 40（C03） ─────────────────────────┬ 右栏 360 ┐
│          │ ◀ C19 工具栏 48（画布左侧浮动，距边 12）    │ 工具面板 │
│          │                                            │ C05/C06  │
│          │            画布（C10，无限）                │          │
│          │                                            │          │
│          │                    C18 小地图（左下 160×110）│ C20 右下 │
└──────────┴────────────────────────────────────────────┴──────────┘
```
- 画布坐标原点任意；缩放范围 10%–400%；缩放控件距右下 16。
- 视口右上：面包屑（C07，仅在有父板时出现）+ 协作位留空（不实现）。

**元素**：C10 C11 C12 C13 C14 C15 C16 C17 C18 C19 C20 C21 C22 C05 C06 C07 C09 C11 的色板

**状态**
- `默认`：显示卡片、分区、文本、图片对象；缩放 100%。
- `空板`：画布中央一张引导卡（"拖入文件 / 双击空白新建"），三行图例，随首次操作消失且不再出现。
- `加载`：画布底色立即出现，卡片以 C66 占位（≤ 300ms 后换真内容）。
- `选中（单个）`：对象描边转强调色（V6），浮出 C22。
- `选中（多个）`：显示选择框外框 + 数量角标；C22 换成批量版。
- `聚焦模式`：非选中对象及非邻居对象降到 15% 不透明度，其余不变。
- `只读`：所有编辑类按钮隐藏，C19 只留选择与缩放。

**主要交互**

| 动作 | 反馈 | 说明 |
| --- | --- | --- |
| 拖拽对象 | 跟手（零可见延迟） | 起拖 120ms 后显示坐标，不显示"抓手"光标以外的装饰 |
| 拖动到与邻居同轴 | 出现 C17 淡蓝提示线，松手**一次吸附到位** | 吸附阈值 6px；不在吸附点时不做"磁性拉扯" |
| 双击空白 | 就地新建卡并进入编辑（光标在首行） | 不在中央弹窗 |
| 右键空白 / 右键对象 | C21，菜单项按对象类型变化 | 菜单不出现在屏幕边缘外 |
| 框选（拖空白） | C16 半透明框，选中实时增删 | `Shift` 加选，`Alt` 减选 |
| 滚轮 | 上下滚动；`⌘+滚轮` 缩放；`Shift+滚轮` 横移 | 缩放以指针为锚点 |
| 空格 + 拖动 | 平移（光标变抓手） | 松开空格恢复原工具 |
| 拖入卡片库卡片 | 落点显示虚线占位 | 松手后吸附到最近网格 |
| 拖出连线端点 | 连到对象高亮；空白处松手 = 取消 | 连线落点有 8px 容差 |
| 悬停卡片 | 浮出 C22 精简版（改色/折叠/更多/AI） | 不遮挡卡片标题 |

**键盘**：`V` 选择 / `N` 新建卡 / `T` 文本 / `S` 分区 / `L` 连线 / `Space` 平移 / `⌘0` 适配 / `⌘+` `⌘-` 缩放 / `⌘Z` `⇧⌘Z` 撤销重做 / `Delete` 删除选中 / `Esc` 取消选择。

**验收**
- [ ] 150 个对象的板：拖动、缩放仍跟手（无可见滞后与掉帧感）。
- [ ] 拖到与邻居同轴后松手，无需任何微调（≥ 90% 的情况）。
- [ ] 框选 12 张卡 → 批量改色 → `⌘Z` 一次恢复。
- [ ] 空板 5 秒内能被理解（有引导卡，且不阻挡操作）。
- [ ] 缩放 10% 与 400% 下，卡片圆角与描边不出现视觉断裂。
- [ ] 从卡片跳转到它所在的另一块板，视口**定位到该卡**（不是板左上角）。

**因果**：吸附若需二次微调，板子会显得潦草，用户就不敢摆乱（K5）；没有撤销，用户只会整齐堆叠（K6）。

## S03 · 卡片阅读

**目的**：时刻 B——读懂一张卡，并知道它和什么有关。

**进入方式**：画布上单击卡片（单击进入阅读，双击进入编辑）/ 卡片库点卡 / 右栏卡片库点卡（引用方式，不新开 tab）/ `@` 提及后点击。

**布局**
```
┌ 标签条 40 ──────────────────────────────────────────┬ 右栏 360 ┐
│ 顶部：标题（可编辑）+ 右侧动作组（更多 / 出现在这些板）│ 信息     │
│ 正文：块编辑器只读态（行宽最大 680，居中）             │ 回链     │
│ 底部：字数 · 创建/修改时间                            │ 目录     │
└─────────────────────────────────────────────────────┴──────────┘
```
- 正文与 S04 完全同构，只差可编辑性——**不允许阅读态与编辑态有两套排版**。

**元素**：C30（只读） C33 C34 C35 C39 C46 C63 C64

**状态**
- `默认`：940ms 后正文可交互；悬停任意块左侧浮出拖拽手柄（6 个点）。
- `空卡`：显示占位提示"输入内容，或按 `/` 插入块"。
- `加载`：标题立即出现（已知），正文骨架。
- `他人引用模式`：右栏打开时正文缩窄，行宽不变。

**主要交互**

| 动作 | 反馈 |
| --- | --- |
| 单击任意块 | 进入编辑态并把光标放在点击处（同 S04） |
| 悬停标题 | 右侧出现"复制链接 / 出现在这些板" |
| 点击提及（`@` 链接） | 悬停 300ms 弹出卡预览（C63）；点击打开 |
| 右栏"信息" | 标签、属性、所在白板、被谁提及 |
| 右栏"回链" | 按来源分组（卡片/白板/日志），每条可跳转 |

**验收**
- [ ] 从板到卡的往返，回来后板的视口与选中态不变。
- [ ] 一张 5000 字的卡，滚动到 80% 位置无卡顿感。
- [ ] 右栏面板切换（信息 ↔ 回链 ↔ 目录）时正文**不重排**。
- [ ] 提及悬停预览 300ms 内出现，移开后 200ms 内消失。

**因果**：阅读与编辑两套排版会让用户"编辑时找不到刚才读的地方"（V4 一致性）。

## S04 · 卡片编辑（编辑器激活）

**目的**：时刻 B——让"写下来"这一步不打断思考。

**进入方式**：在 S03 单击正文 / 画布双击卡片 / 键盘 `N` 新建后。

**布局**：同 S03；编辑态额外显示：块左侧拖拽手柄（悬停）、行首 `+`（新增块）、底部插入区。

**元素**：C30 C31 C32 C39 C63 C66

**状态**
- `默认`：光标处显示插入点；不显示任何边框（编辑态不画外框，避免"输入框"感）。
- `斜杠菜单`：`/` 触发 C31，距光标 4px，屏幕边缘自动翻转。
- `提及菜单`：`@` 触发 C32，分组为"卡片 / 白板 / 块 / 日期"。
- `拖拽中`：块半透明跟随，落点显示 2px 插入线。
- `只读块`：媒体块与嵌入块右下角有锁形标记。

**主要交互**

| 动作 | 反馈 | 键盘 |
| --- | --- | --- |
| 输入 `/` | 块菜单（8 种块 + 搜索） | `Esc` 关闭；`↑↓` 选择；`Enter` 插入 |
| 输入 `@` | 提及菜单，可直接搜索 | 同上 |
| 块前悬停拖柄 | 拖动换位，落点插入线 | `⌥↑/↓` 移动块 |
| 行首退格 | 块降级（列表→正文→合并） | — |
| 选中一段文字 | 浮出 mini 工具条（加粗/高亮/转为卡/复制链接） | `⌘B` `⌘I` `⌘K` 链接 |
| 粘贴多行 | 自动按换行拆块 | — |
| 输入 `[ ]` | 转为待办块 | — |

**验收**
- [ ] 连续输入 10 分钟无可感知卡顿；`Enter`/`Tab`/`Backspace` 的块级行为符合直觉（3 人试，无需解释）。
- [ ] 编辑器排版与 S03 完全一致（同字号同间距；截图对比 0 差异）。
- [ ] `/` 菜单在屏幕底部时向上翻转，永不出界。
- [ ] 撤销覆盖块级操作（拆分/合并/移动/改类型）。

**因果**：编辑态若画外框/换字体，用户会把"写"和"读"当成两件事，破坏连续感（V4）。

## S05 · PDF 阅读与标注

**目的**：时刻 A——把"读过的段落"变成"可以带走的卡"。

**进入方式**：画布上的 PDF 对象双击 / 卡片库中的 PDF 卡 / 左栏"读"入口。

**布局**
```
┌ 顶部 40：文件名 · 页码 · 大纲按钮 · 更多 ──────────────────────────┐
│ 左侧：页面视图（可滚动，双页可选） │ 右栏 360：笔记 / 标注列表 / AI │
│ 底部：页码 · 缩放 · 适配宽度                                      │
└──────────────────────────────────────────────────────────────────┘
```

**元素**：C36 C37 C05 C63 C46 C11

**状态**
- `默认`：整页可见（适配宽度）；文本层可选。
- `选择中`：划过的文字高亮（低饱和，V7 的蓝/绿/黄三色），松手浮出 C37。
- `已标注`：标注底色常驻；悬停显示"摘录成卡 / 加注 / 删除"。
- `选区工具条`：位于选区上方 8px，宽度自适应，**永不覆盖选区**；上方空间不足时翻到下方。

**主要交互**

| 动作 | 反馈 | 键盘 |
| --- | --- | --- |
| 拖选文字 | 松手出 C37（4 色 + 摘录成卡 + 加注 + AI 解释） | — |
| 点"摘录成卡" | 就地生成卡片预览（含出处：文件 · 页码 · 段落序号），可编辑标题后确认 | `Enter` 确认 |
| 点"AI 解释" | 右栏打开 AI，自动带入选区作为上下文 | — |
| 点已标注处 | 浮出标注菜单 | — |
| `⌘F` | 文件内搜索，结果侧列 | — |

**验收**
- [ ] 划词到成卡 ≤ 3 次操作，且卡片自动带出处并可跳回该页该段。
- [ ] 选区工具条在任何位置都不遮挡所选文字（含选中贴近页底时）。
- [ ] 页面滚动时标注不错位（缩放 80%–200% 均正确）。
- [ ] 右栏打开时，页面视图按比例收窄，不出现横向滚动。

**因果**：工具条遮字，用户必须先取消选择才能继续读，读-抓被切断（K4）。

## S06 · 复习会话

**目的**：时刻 C——5 分钟内过完该复习的卡，并留下掌握度。

**进入方式**：S01 右栏"开始复习" / 左栏"复习" / `R`。

**布局**
```
┌ 顶部 40：今天是 10 月 21 日 · 还剩 5 张 · 退出 ─────────────────┐
│                ┌── 卡片 640×420 居中 ──┐                        │
│                │  正面：问题 / 挖空     │                        │
│                │  背面：答案 + 出处     │                        │
│                └───────────────────────┘                        │
│        底部：[还是模糊]  [懂了]        右侧：进度点 ●●●○○        │
└──────────────────────────────────────────────────────────────────┘
```
- 背景使用画布底色（V1），不新建"模态弹窗"外观——复习是主区域的一个 tab，不是覆盖层。

**元素**：C42 C43 C41 C46 C09

**状态**
- `正面`：只显示问题；点击卡片或按空格翻面。
- `背面`：答案 + 出处链接 + 掌握度选择。
- `空队列`：一句"今天没有要复习的"，附"随便翻一张"。
- `完成`：一句"今天到这里就够了" + 明日数量预览；3 秒后自动回到 S01。
- `翻面中`：150ms 轴翻动（V13），期间不可点击。

**主要交互**

| 动作 | 反馈 | 键盘 |
| --- | --- | --- |
| 点击卡片 | 翻面 | `Space` |
| 「懂了」 | 卡片飞出（120ms），掌握度 +1，进度点填充 | `→` |
| 「还是模糊」 | 卡片回队列末尾，掌握度不变，下次间隔缩短 | `←` |
| 点击出处 | 侧滑打开原文（不离开复习会话，`Esc` 返回） | `O` |
| 退出 | 保留进度，提示"还剩 N 张" | `Esc` |

**验收**
- [ ] 从 S01 点击到看到第一张卡 ≤ 1 次交互、≤ 500ms。
- [ ] 5 张卡在 3 分钟内可完成（含翻面），全程无需鼠标亦可用键盘完成。
- [ ] 「还是模糊」的卡在同一会话内会再次出现（不丢）。
- [ ] 退出后再次进入，进度与队列顺序保持。

**因果**：任何"先选范围/先配置"的步骤，都会让用户第三次就不打开复习（K7）。

## S07 · 每周回顾

**目的**：时刻 C——给"这周有进步"一个可看见的证据，让学习有累积感。

**进入方式**：S01 的 ④ 点击 / 左栏"今日"内的入口。

**布局**：主区单栏（最大 720），自上而下：一句话总结 → 四个数字（新增卡/连线/AI 对话/复习正确率）→ 最薄弱概念（2 张卡）→ 下周建议（1 条）。

**元素**：C47 C11 C39 C60

**状态**：`默认` / `数据不足`（少于 7 天：改为"从上周开始记录"）/ `加载`（骨架）。

**主要交互**：点最薄弱的概念卡 → 右侧打开该卡；点"下周建议"→ 跳到对应主题。

**验收**
- [ ] 一屏读完，不需要滚动（1440×900）。
- [ ] 数字与"薄弱概念"能在 2 秒内被理解，不出现难以解读的指标名。
- [ ] 数据不足时不说"暂无数据"，而是给出起点。

**因果**：无累积感的学习工具，第 3 周流失（时刻 C 的核心动机）。

## S08 · 卡片库

**目的**：时刻 B——当卡多到画布放不下时，仍能"按条件找一批卡"。

**进入方式**：左栏"卡片库" / `⌘L`。

**布局**
```
┌ 顶部 44：视图切换（网格/列表/时间线）· 排序 · 批量操作 ────────────┐
```

**目的**：时刻 A——接住"随手扔进来"的东西，不让它们散落。

## S12 · 全局搜索

**目的**：任何时刻找任何东西（卡 / 板 / 标签 / 日志 / 对话）。

**进入方式**：`⌘O` / 左栏搜索图标。

**布局**：居中浮层（宽 640，高 ≤ 520），顶部输入（C57），下方结果列表（C59）按类型分组；右栏预览（打开时浮层右移 360）。

**元素**：C57 C59 C51 C63 C46

**状态**：`空查询`（显示最近 5 条 + 常用入口）/ `有结果`（按类型分组，每组前 3 条 + "更多"）/ `零结果`（"没有找到，试试去掉筛选"）/ `筛选中`。

**主要交互**：输入即时结果（≤ 150ms）；`↑↓` 选择，`Enter` 打开（新 tab 或当前 tab，`⌘Enter` 新 tab）；`Esc` 关闭并回到原位置。

**验收**
- [ ] 1000 张卡下输入到首屏结果 ≤ 150ms。
- [ ] 结果中能看出"它属于哪块板/哪个标签"（位置上下文）。
- [ ] 零结果时给出可操作建议，不是死路。

**因果**："找东西"与"做事"混在一个入口会让两者都变慢（K11）。

## S13 · 命令面板

**目的**：让熟练用户不离开键盘完成动作。

**进入方式**：`⌘K`。

**布局**：居中浮层（宽 560，高 ≤ 480）。列表项 = 图标 + 动作名 + 右侧快捷键。

**元素**：C58 C60 C61

**状态**：`默认`（按频率排序 + 分组：视图/卡片/画布/复习/导出）/ `搜索中`（模糊匹配）/ `无匹配` / `禁用项`（灰显 + 原因提示）。

**主要交互**：`↑↓` 选择、`Enter` 执行、`Esc` 关闭；执行后浮层立即关闭并给出 C09 轻提示（可撤销的动作用"撤销"按钮）。

**验收**
- [ ] 常用 12 个动作都能在 3 次按键内完成（打开→输入→回车）。
- [ ] 每个动作右侧都标出真实快捷键；与快捷键总表 100% 一致。
- [ ] 禁用项必须说明为什么禁用（例如"当前没有选中对象"）。

**因果**：键位是重度用户留存的开关（I3）。

## S14 · 新建学习主题（上传 → 解析 → 成板）

**目的**：时刻 A 的起点——把一堆材料，一次变成一个可学的主题。

**进入方式**：左栏"新建学习主题" / S01 空态的引导。

**布局**：三步单栏（最大 640）：① 拖入材料（多文件）→ ② 确认解析结果（每份材料一行：类型/页数/是否可解析）→ ③ 命名主题 + 是否生成起始板。

**元素**：C60 C61 C62 C65 C66 C09

**状态**：`空` / `上传中`（每行独立进度，允许其余行继续）/ `解析失败`（该行给出替代选项："作为图片卡片导入"）/ `完成`（自动跳 S02 并展示首次进入提示）。

**主要交互**：拖入即开始（不需要点"开始"）；解析进度逐行推进；`Esc` 取消当前文件但不取消整个流程。

**验收**
- [ ] 拖入 3 个文件后 3 秒内至少看到第一张卡出现在板上。
- [ ] 单份材料失败不影响其它材料。
- [ ] 新主题的起始板不为空——至少有"该从哪读起"的一张引导卡。

**因果**：首屏若停在"上传成功"，用户不知道下一步做什么（K1 的入口侧）。
