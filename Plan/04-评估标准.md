# 04 · 评估标准

> 这套标准的唯一目的：让"好不好"不再由职位高低或说话声量决定。
> 评审只需要做两件事：**照着测试走一遍**，**在 8 个维度上打分**。

---

## 一、五个体验测试

任何一个 Stage 的版本都可以直接跑这五个测试。它们的共同点是：**不需要懂设计，任何人都能执行**。

### T1 · 截图指纹比对（每个 Stage 必做）

- **方法**：用同样的内容、同样的视口（1440×900），截取实现画面；把 01 文档 §6 的 13 条指纹逐条对照参考图。
- **通过线**：13/13 全过（允许在容差内偏离；容差外即失败）。
- **记录**：一张两栏表（左：参考图条目；右：实现截图 + 勾/叉 + 偏离说明）。
- **为什么用截图**：截图会暴露所有"平时看着还行"的问题——间距不匀、描边过重、字重混乱，在并排对比下无所遁形。

### T2 · 三秒辨识（风格是否成立）

- **方法**：让 5 个人各看一张应用截图 3 秒，然后回答：哪些是卡片、哪些是分区、哪些是文本元素、哪些是浮层工具？再问一句"这是一款什么产品"。
- **通过线**：四类对象辨识准确率 ≥ 90%；"什么产品"的回答中出现"学习 / 知识 / 笔记"任一关键词 ≥ 4/5。
- **失败的含义**：不是用户眼花，而是**层次设计失败**——形状/色彩/描边没有承担起区分职责。

### T3 · 零说明任务（导航与直觉是否成立）

- **方法**：不给任何提示、不给文档，只给一句话背景（"这是一个学习工具，里面有你的资料"），让陌生人完成 4 个任务：
  1. 找到你昨天读过的那份 PDF；
  2. 把其中一段划线变成一张自己的卡片；
  3. 把这张新卡和你已有的另一张卡连起来；
  4. 找出今天需要复习的 3 张卡。
- **通过线**：完成率 ≥ 80%；全程**跳页次数 = 0**；每人的"卡住点"不超过 1 处。
- **记录**：录屏 + 卡住点时间戳。卡住点就是下一版最该改的地方。

### T4 · 孤岛测试（低耦合与风格一致的双重检验）

- **方法**：随机抽 3 个零件（如"连线""标签胶囊""复习队列"），脱离应用，单独放在一个空白页面上展示。
- **通过线**：
  - 5 个观察者中 ≥ 4 个认为"它属于刚才那个产品"（风格一致）；
  - 零件在无上下文时行为自洽（连线仍能连两个东西、胶囊仍可删除）；
  - 换掉其中一个零件的外观，其它零件不需要改动（0 处连带变化）。
- **为什么要做这个测试**：它能同时抓出"风格漂移"和"隐藏耦合"——这两件事在正常浏览时几乎看不出来，只在被单独拎出来时暴露。

### T5 · 五分钟陌生用户（整体是否成立）

- **方法**：陌生人用 5 分钟，独立完成一次完整闭环：采（拖入一份材料）→ 抓（划线成卡）→ 连（把两张卡连起来）→ 复（在复习队列里过 3 张卡）。
- **通过线**：5 分钟内完成 ≥ 3 步，且**没有任何一步需要人教**；结束后能说出"下次我会用它做什么"。
- **失败的含义**：闭环某处断裂（通常是"抓"或"复"），而不是"用户不会用"。

## 二、八维评分卡

每个维度 1–5 分。**用户是唯一评审官**，不需要解释专业理由，只需要回答"用起来是不是这样"。

| # | 维度 | 1 分（不及格） | 3 分（可用） | 5 分（好） |
| --- | --- | --- | --- | --- |
| D1 | **风格一致性** | 前后界面像两个产品；卡片有三种长相 | 大体一致，个别地方字体/圆角不统一 | 截图排在一起像同一套设计系统出品 |
| D2 | **空间与层次** | 分不清哪些是分组、哪些是内容；靠重阴影硬分层 | 层次可辨，但需要盯一下 | 一眼看出"这是一组、那是单张、这是浮层" |
| D3 | **交互手感** | 拖动有滞后、缩放跳变、吸附粘手 | 基本跟手，偶有顿挫 | 像在纸上移动实体，想放哪就放哪 |
| D4 | **连续流** | 一次任务要跳 3 个页面 | 可以在一屏内完成，但需要开合面板 | 从头到尾没离开过同一个平面 |
| D5 | **认知负荷** | 满屏都是东西，不知道先看哪 | 有点乱，但能找到重点 | 信息很多，但安静、不吵、知道从哪开始 |
| D6 | **学习闭环** | 只能记录，记完就断 | 能读能记能连，但没有"回头再看" | 采→读→抓→连→问→复，六步都在一个空间里 |
| D7 | **可逆与安全感** | 误操作找不回来，不敢乱动 | 主要操作能撤销 | 什么都敢试，因为一步就能退回去 |
| D8 | **跨场景一致性** | 暗色是反色，空态是"暂无内容" | 暗色能用，空态有提示 | 明暗两套都像同一个产品的两副表情；空态也在引导下一步 |

### 闸门规则

| 阶段 | 要求 |
| --- | --- |
| 每个 Stage 结束时 | 平均 ≥ 3.5；无单项 < 2；D1、D4 不得低于 3 |
| Stage 4 结束时 | D3 ≥ 4（画布手感必须在这一阶段达标） |
| Stage 6 结束时 | D6 ≥ 4（差异化必须被感知到） |
| Stage 8 结束时（总验收） | 平均 ≥ 4.0；**D1、D4、D6 ≥ 4.5**；无单项 < 3 |

> 关键三项是 D1（风格）、D4（连续流）、D6（学习闭环）——它们对应本次任务的三个核心诉求：**像、顺、是学习空间**。

## 三、感知性能预算（用"感觉"描述，不用毫秒堆砌）

| 场景 | 用户应该感觉到 | 可接受的极限 |
| --- | --- | --- |
| 点击任何按钮/卡片 | 立刻有反应（按下即变） | 反应晚于"眨一次眼"就算失败 |
| 拖动对象 | 对象贴着指针，没有拖影、没有追赶 | 出现可见滞后即失败 |
| 缩放画布 | 连续变化，不跳帧、不糊 | 任何一次卡顿都算失败 |
| 打开一张卡片 | 结构立刻出现，内容紧随其后 | 空白等待超过"数一下的三秒"即失败 |
| 打开一块大板（150+ 对象） | 有内容的骨架先到，细节随后 | 超过一秒钟的白屏即失败 |
| AI 回答 | 1 秒左右出现，并逐段流出 | 超过 2 秒无反馈即失败 |
| 切换标签页 | 立即切换，滚动位置不丢 | 位置丢失或闪烁即失败 |
| 撤销 | 立即回到上一状态，无过渡动画 | 需要等动画 = 失败 |

**原则**：宁可少一个功能，也不要一次"卡一下"。一次卡顿会被记住一整天。

## 四、反模式清单（出现任一条，直接判不合格）

这些是最容易在"高保真原型"里出现的错误，也是评审最容易被糊弄过去的地方。

| 反模式 | 为什么致命 |
| --- | --- |
| 用重阴影 / 渐变大色块制造层次 | 一旦靠装饰分层，密度一高就脏；HeptaBase 的层次几乎全靠描边与留白 |
| 满屏彩色 | 颜色一旦用于装饰，就失去了"分类"的功能性 |
| 用抽屉 / 弹窗承载主要任务 | 主要任务必须在平面内完成；弹窗只用于确认与临时选择 |
| 关键操作只在悬停时出现 | 触摸与新手都会找不到；悬停只用于"加速"，不能用于"发现" |
| 菜单套菜单超过两层 | 学习工具的用户不是工程师，深层菜单等于不存在 |
| 没有撤销 | 用户会退回"整齐摆放"，空间范式失效 |
| 动效超过 250ms / 大量弹跳 | 用户会为了快而关掉动画，然后界面变得"硬切" |
| 暗色模式 = 反色 | 反色会让卡片失去层次（阴影在深色下不可见） |
| 空态写"暂无内容" | 空态是产品最有价值的一屏，它应该告诉用户"下一步做什么" |
| 每个界面各自定义字号/圆角 | 这就是风格漂移的起点，也是组件耦合的第一个信号 |

## 六、为什么用这套而不是"看感觉"

- **可复现**：同一个版本，不同人跑同一组测试，结论差异不会超过 1 分；
- **可归因**：分数低时能定位到具体维度与具体测试（"D3 低 → 手感测试失败 → 拖动滞后"），而不是"再改改"；
- **抗漂移**：指纹与孤岛测试都是"跨时间"的检查，能抓住"改着改着就不像了"；
- **对用户公平**：全部指标都从"用户能不能做成事"出发，而不是"设计上是否时髦"。
