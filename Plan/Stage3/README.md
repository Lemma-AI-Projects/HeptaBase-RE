# Stage 3 · 施工方案（读 → 抓）

> 交付：**S03 卡片阅读 / S04 卡片编辑 / S05 PDF 阅读与标注** + 「划词 → 成卡 → 落板」闭环
> 依据：[04-阶段任务与验收](../04-阶段任务与验收.md) 3.1–3.12｜[03-组件契约](../03-组件契约.md) C30–C37
> 状态：T1–T6 已落地；3.4 拖动换位、3.10 视频字幕未做

---

## 1. 这一阶段要成立的一件事

**同一张卡，读态和写态长得一模一样；在 PDF 上划一段，三次操作内变成带出处的卡，还能跳回去。**

三段动作：
1. 打开卡片 → 读（S03）
2. 点正文 → 就地编辑，`/` 插块、`@` 提及（S04）
3. 打开 PDF → 划词 → 浮层「摘录成卡」→ 改标题 → 确认 → 板上多一张卡（S05 → S02）

## 5. 验收映射（04 的 9 条）

| 验收 | 怎么证 |
| --- | --- |
| 划词→成卡 ≤ 3 次操作 | 划选 → 点「摘录成卡」→ 确认（标题可改），计数 3 |
| 浮层不遮挡所选文字 | 选区贴页底/贴边两张图 |
| 阅读态与编辑态排版 0 差异 | 同位置两张截图叠差 |
| 板 ↔ 卡往返保留视口 | S02 视口存在 store，返回时复用 |
| 撤销覆盖拆分/合并/移动 | `⌘Z` 三步连续 |
| 右栏面板切换正文不重排 | 宽度固定，只换内容 |
| 提及悬停 300ms 出现 | 已有 C64 复用 |
