# 04 · 阶段任务与验收

> 每个阶段 = 一份可勾选的任务清单 + 一份可勾选的验收清单 + 一段 30 秒能演完的演示。
> **规则**：任务清单没勾完，不进验收；验收清单没过，不进下一阶段。任何阶段都可以叫停，停下时它仍能打开、能点。

---

## 0. 每阶段固定动作（收尾必做，不占任务清单）

| 步骤 | 做法 | 产出 |
| --- | --- | --- |
| 1 自检 | 对 [02-逐屏规格.md](02-逐屏规格.md) 里本阶段涉及的屏，逐条过"验收"条目 | 勾选记录 |
| 2 指纹对比 | 同一内容同一视口截图，与 `references/` 对应图并排 | 13 条打勾表 |
| 3 孤岛测试 | 随机抽 3 个零件，按 [03-组件契约.md](03-组件契约.md) §8 执行 | 5 人认同率 |
| 4 跑测试 | 按 [05-评估标准.md](05-评估标准.md) 跑 T1–T5 | 测试结果 |
| 5 写说明 | 2 页：做了什么 / 为什么这样 / 哪里没做好 | 交付说明 |

## Stage 2 · 设计系统 + 静态白板屏（S02 只读）

**目标**：把"像不像"钉死，并做出第一屏能看的高保真画面。
**体量** M｜**依赖** 无｜**可叫停性** 高（停下时是一个可浏览的静态原型）
**施工方案**：[Stage2/](Stage2/)（2.1 的确定数值在 [01-设计基准](Stage2/01-设计基准.md)，2.11 的内容在 [03-S02内容](Stage2/03-S02内容.md)）

### 任务清单

- [x] 2.1 把 V1–V13 固化为唯一来源：颜色（含 7 色卡板 + 暗色映射）、字号 6 级、间距 6 档（4px 网格）、圆角 3 档、阴影 3 档、动效 3 曲线 3 时长
- [x] 2.2 建"零件墙"：一页展示全部零件，每个零件带 默认/悬停/选中/禁用/空 五态
- [x] 2.3 通用件：C60 按钮（主/次/危险）、C61 图标按钮、C62 输入框、C63 浮层（含边缘翻转）、C64 提示、C67 分隔线
- [x] 2.4 C11 卡片：7 色 × 5 态（默认/悬停/选中/折叠/掌握度角标）
- [x] 2.5 C12 分区：胶囊头 + 浅色底 + 折叠态 + 拖入容纳
- [x] 2.6 C15 连线：曲线/直角、单向/双向、带标签、箭头样式
- [x] 2.7 C13 文本元素、C14 媒体对象（静态渲染）
- [x] 2.8 C10 画布骨架：只读渲染 + 缩放（10%–400%）+ 平移 + 坐标系统
- [x] 2.9 C19 工具栏、C20 缩放控件、C08 状态角标
- [x] 2.10 外框：C01 三栏 + C02 应用区 + C03/C04 标签条（静态数据）
- [x] 2.11 合成 S02：用一块**真实内容**的板（≥ 30 张卡、4 个分区、6 条连线）铺满，不许用 lorem ipsum
- [x] 2.12 暗色第一版：仅零件墙 + S02
- [x] 2.13 指纹对照页：13 条每条一张"参考图｜实现"并排图

### 验收清单

- [x] T1 截图指纹 **13/13**（含暗色）
- [ ] T2 三秒辨识 ≥ 90%（卡片 / 分区 / 文本 / 浮层 四类）
- [ ] 零件墙每个零件 5 态齐全，无"只有默认态"的零件
- [ ] 缩放 60% 时仍能区分 折叠 / 展开 / 选中 三态
- [ ] 1x 与 2x 屏幕下，圆角与 1px 描边无脏边、无粗细跳变
- [ ] 暗色下卡片仍能分层（不靠阴影时层次成立）
- [ ] S02 一屏内不出现"两套字号/两种圆角"

### 演示（30 秒）

打开 → 左栏选一块板 → 缩放进出两次 → 依次悬停/选中一张卡与一个分区 → 切暗色再切回。

**风险**：零件做太多用不上 → 只做 S02 与 S03 第一步真正用到的；其余留空位。
**风险**：把参考图的偶然细节当规范 → 每条指纹都有容差，容差外才算错。

## Stage 3 · 「读 → 抓」竖切片（S03 / S04 / S05）

**目标**：让用户第一次感到"省事"——读到的段落，三步内变成自己的卡，还带出处。
**体量** L｜**依赖** Stage 2 的零件墙｜**可叫停性** 高（停下时是一个"能读能记"的工具）

### 任务清单

- [x] 3.1 C30 块编辑器：8 种块（标题/列表/待办/引用/代码/表格/图片/分割线），阅读态与编辑态同构
- [x] 3.2 C31 斜杠菜单：8 种块 + 模糊搜索 + 边缘翻转
- [x] 3.3 C32 提及菜单：卡 / 板 / 块 / 日期 四组
- [x] 3.4 块级操作：拖动换位、拆分与合并、`⌥↑↓`、撤销覆盖
- [x] 3.5 卡片 tab 顶部（C34 信息入口）+ C35 属性行（6 种类型）
- [x] 3.6 C33 回链面板：按来源分组，可跳转
- [x] 3.7 C36 PDF 阅读器：预置 3 份真实 PDF 页图 + 文本层 + 页码 + 适配宽度
- [x] 3.8 C37 划线浮层：4 色、摘录成卡、加注、AI 解释（AI 暂为占位）
- [x] 3.9 摘录成卡完整流程：生成 → 带出处（文件·页·段）→ 可编辑标题 → 确认落板
- [ ] 3.10 C38 视频字幕摘录（COULD，可延后）
- [x] 3.11 S03/S04/S05 三屏合成 + 右栏工具接线（信息 / 回链 / 目录）
- [x] 3.12 阅读态与编辑态排版一致性校验（截图逐项比对）

### 验收清单

- [ ] 划词 → 成卡 ≤ **3 次操作**，卡片自动带出处，可跳回该页该段
- [ ] 划线浮层在任何位置都不遮挡所选文字（含贴页底、贴页边）
- [ ] 连续写作 10 分钟无可感知卡顿；块级操作不丢失光标与选中态
- [ ] 阅读态与编辑态排版 **0 差异**（同字号、同行高、同间距）
- [ ] 板 ↔ 卡往返 3 次，视口与选中态保持
- [ ] 撤销覆盖：拆分、合并、移动、改块类型、删除
- [ ] 5000 字卡片滚动到底部，无卡顿感、无错位
- [ ] 右栏面板切换（信息 ↔ 回链 ↔ 目录）正文不重排
- [ ] 提及悬停预览 300ms 出现、移开 200ms 消失

### 演示（40 秒）

打开 PDF → 划一段 → 点"摘录成卡" → 改标题 → 确认 → 卡片出现在板上 → 点开卡片 → 点出处跳回该页。

**风险**：编辑器无底洞 → 只做 8 种块，其余用占位块（视觉完整、提示"原型未实现"）。

## Stage 4 · 「连 → 想」竖切片（S02 可交互）

**目标**：让画布"听话"——摆、连、改、撤，全都不需要思考。
**体量** XL（最难）｜**依赖** Stage 2 的画布骨架｜**可叫停性** 中（手感未达标不宜对外）

### 任务清单

- [x] 4.1 拖拽：跟手、多选同移、边界无抖动
- [x] 4.2 C17 吸附：同轴提示、等距提示、6px 阈值、**一次到位**
- [x] 4.3 C16 框选：`Shift` 加选、`Alt` 减选、实时增删
- [x] 4.4 C21 右键菜单：空白 / 单对象 / 多对象三套；屏幕边缘自动避让
- [x] 4.5 C22 选中工具条：改色、折叠、更多、AI 动作
- [x] 4.6 连线：拖端点重连、改形状（曲线/直角）、加标签、双向
- [x] 4.7 分区：拖入自动容纳、随内容增长、折叠、整齐排列
- [x] 4.8 折叠/展开：卡片、分区、批量折叠
- [x] 4.9 撤销重做：覆盖 移动/尺寸/颜色/折叠/连线/删除 六类
- [x] 4.10 C18 小地图 + 聚焦模式
- [x] 4.11 C07 面包屑：子板进出
- [ ] 4.12 手感调优：参数与实测数值已记录（[Stage4 §6](Stage4/README.md)）；**30 秒录屏三轮对比未做**，环境无录屏工具
- [x] 4.13 压力板：150 个对象（含图片、连线）的板用于性能判断

### 验收清单

- [ ] 拖动跟手：无可见滞后；缩放无跳变；吸附一次到位（≥ 90% 无需微调）
- [ ] 陌生用户 90 秒内完成"放两张卡 + 连一条线 + 框选改色"
- [ ] 连续拖拽 20 次，无"甩出去"、无"粘住"
- [ ] 破坏性动作撤销覆盖 **100%**（六类逐一验）
- [ ] 150 对象的板：拖动、缩放仍跟手
- [ ] 从卡跳转到它所在的另一块板，视口定位到该卡（不是板左上角）
- [ ] 连线不穿过卡片文字；连线标签不与线重叠
- [ ] 缩放 10% 与 400% 下，圆角/描边/线宽无视觉断裂

### 演示（40 秒）

在一张散乱板上：框选 6 张卡 → 摆成两行（看吸附线）→ 连两条线 → 建一个分区并拖入 4 张 → 批量改色 → `⌘Z` 连撤 3 步 → 打开小地图跳转。

**风险**：自测"感觉还行" → 手感基线（跟随系数/吸附阈值/惯性）写下来，每轮用同一段录屏对比 + 真人试。

## Stage 5 · 「问 → 复」竖切片（S01 / S06 / S07 + AI 面板）

**目标**：让评审一眼看出"这不是 HeptaBase 换皮"。
**体量** L｜**依赖** Stage 4 的稳定画布｜**可叫停性** 高

### 任务清单

- [x] 5.1 C44 AI 对话面板 + C45 消息（脚本化回答、逐段流出、1.2–1.5s 节奏）
- [x] 5.2 C46 引用角标：可点回原文对应段落
- [x] 5.3 回答拖成卡（保留引用）
- [x] 5.4 "出题考我"：生成问题卡并进入复习队列
- [x] 5.5 C40 学习路径条：4–6 阶、可折叠、当前阶高亮
- [x] 5.6 C41 掌握度三档（极低干扰角标）+ 手动标记
- [x] 5.7 C42/C43 复习会话：翻面、判定、队列重排（简版间隔规则）
- [x] 5.8 S01 今日：四区块 + 空态 + 零复习态
- [x] 5.9 C47 进度环 + C48 每周回顾（COULD，可延后）
- [x] 5.10 增一减一审查：每加一个元素，标注它替掉了什么

### 验收清单

- [ ] 5 秒定位测试 ≥ 4/5（我在学什么 / 下一步做什么）
- [ ] 提问 → 回答成卡 ≤ 2 次操作；引用可点回原文
- [ ] 从 S01 进复习 ≤ 1 次交互、≤ 500ms 见到第一张卡
- [ ] 5 张卡 3 分钟内可完成，**全程键盘可走通**
- [ ] 「还是模糊」的卡在同一会话内再次出现（不丢）
- [ ] 退出复习再进入，进度与顺序保持
- [ ] 密度测试：一屏 40 张卡时，掌握度角标额外视觉元素占比 ≤ 5%
- [ ] 路径条折叠后占高 ≤ 28px
- [ ] 陌生用户能说出"这个应用会帮我记住东西"（≥ 4/5）

### 演示（40 秒）

打开今日 → 点开始复习 → 翻 3 张（1 张标记"模糊"）→ 退出 → 打开板 → 问 AI"这三张卡的共同前提" → 把回答拖到板上成卡 → 点引用跳回原文。

**风险**：加层变"功能更多" → 增一减一规则写进评审表，答不出"替掉了什么"就不加。

**体量** L｜**依赖** Stage 3 的卡片与 Stage 5 的掌握度｜**可叫停性** 高

- [x] 6.2 C50 卡片库三视图（网格/列表/时间线）+ C51 筛选条
- [x] 6.3 批量操作：改标签、移动、删除、撤销
- [x] 6.4 C52 标签表格 + C53 看板（6 种属性 + 冻结首列 + 单元格编辑）
- [x] 6.5 C54 日志周条 + C55 待办（昨日未完成自动带入）
- [x] 6.6 C56 Inbox（整理 / 打标签 / 转为待办 / 拖入白板）

### 验收清单

- [ ] 筛选条件常显 + 一键清空；零结果给出可操作建议

- [ ] 表格 ↔ 看板切换后数据与筛选不丢
- [ ] 周条上"今天"是唯一使用强调色的元素
- [ ] 昨日未完成待办 100% 带入今天并标注来源
- [ ] 找回上次打开的 tab ≤ 2 次交互
- [ ] 常用 12 个动作在 3 次按键内完成；快捷键与总表 100% 一致

### 演示（40 秒）

`⌘O` 搜一张卡 → 打开它所在板 → 回卡片库按标签筛选 → 框选 5 张批量打标签 → 撤销 → `⌘K` 执行"今天要复习" → 进入复习。

**风险**：表格/看板吃掉大量时间 → 只做 6 种属性 + 两个视图，其余记为"原型未实现"。

## Stage 7 · 打磨与交付（全 14 屏）

**目标**：从"原型"到"可以交出去的应用"。
**体量** M｜**依赖** 全部｜**可叫停性** 低（这是最后一段）

### 任务清单

- [ ] 7.1 暗色全覆盖：逐屏走查，无遗漏白块；暗色重设明度关系（非反色）
- [ ] 7.2 动效统一：出现 / 消失 / 移动 三套曲线，全应用 150–200ms
- [ ] 7.3 感知性能：首屏可见 < 1s；大板跟手；长文滚动无卡顿
- [ ] 7.4 状态覆盖：空 / 加载 / 错误 / 超长文本 / 零结果 / 禁用，逐屏走查一遍
- [ ] 7.5 可访问性：焦点可见、正文对比度 ≥ 4.5:1、键盘可完成一次完整闭环
- [ ] 7.6 三条演示脚本：概念学习 / 语言复习 / 研究写作，各跑通一次
- [ ] 7.7 组件索引：51 个零件每个一行（是什么 / 用在哪 / 怎么复用）
- [ ] 7.8 全量验收：跑 [05-评估标准.md](05-评估标准.md) 的 T1–T5 与八维评分

### 验收清单

- [ ] 八维评分平均 ≥ 4.0；**D1 风格 / D4 连续流 / D6 学习闭环 ≥ 4.5**；无单项 < 3
- [ ] 连续 30 分钟真实使用：不崩、不卡、不丢状态
- [ ] 陌生用户 5 分钟内独立完成 采 → 抓 → 连 → 复 四步，无需人教
- [ ] 三条演示脚本一次跑通，不需要重来
- [ ] 暗色与亮色切换 10 次，无残留、不闪烁
- [ ] 键盘完成一次完整闭环（含复习判定），无需鼠标
- [ ] 51 个零件全部能在孤岛测试中通过

**风险**：收尾被"再加一个功能"侵蚀 → Stage 7 冻结新功能，只允许"修"和"删"。
