# 05 · 评估标准

> 每阶段收尾跑这套；Stage 8 全量跑。**用户是唯一评审官**：只需照着做一遍、打个分，不需要懂设计。
> 每阶段"做什么"由 [04-阶段任务与验收.md](04-阶段任务与验收.md) 的验收清单负责；这里负责**怎么测、多少分算过**。

---

## 一、五个测试

### T1 · 截图指纹比对（每阶段必做）

- **做法**：同一内容、同一视口（1440×900）截图，与 `references/` 对应图并排，对 [01-范围与基准.md](01-范围与基准.md) §7 的 13 条逐条判。
- **通过线**：13/13（容差内算过）。
- **记录**：两栏表：左参考条目 / 右实现截图 + 勾叉 + 偏离说明。

### T2 · 三秒辨识

- **做法**：5 人各看一张截图 3 秒，回答：哪些是卡片 / 分区 / 文本 / 浮层工具；再答"这是什么产品"。
- **通过线**：四类辨识准确率 ≥ 90%；"学习/知识/笔记"关键词 ≥ 4/5。
- **不过的含义**：不是用户眼花，是形状/色彩/描边没承担起区分职责。

### T3 · 零说明任务

- **做法**：不给说明，只给"这是一个学习工具，里面是你的资料"，让陌生人完成：① 找到昨天读的 PDF ② 把其中一段变成卡 ③ 把新卡与另一张卡连起来 ④ 找出今天要复习的 3 张卡。
- **通过线**：完成率 ≥ 80%；**跳页次数 = 0**；每人卡住点 ≤ 1 处。
- **记录**：录屏 + 卡住点时间戳（卡住点就是下一版最该改的地方）。

### T4 · 孤岛测试

- **做法**：随机抽 3 个零件（按 [03-组件契约.md](03-组件契约.md) §8 的五步），脱离应用单独展示。
- **通过线**：≥ 4/5 认为"属于这个产品"；三态（空/禁用/超长）表现合理；替换一个零件后连带改动 = 0。

### T5 · 五分钟陌生用户

- **做法**：陌生人 5 分钟独立完成 采 → 抓 → 连 → 复。
- **通过线**：≥ 3 步完成，**每一步都不需要人教**；结束后能说出"下次我会用它做什么"。

## 二、八维评分卡

| # | 维度 | 1 分（不及格） | 3 分（可用） | 5 分（好） |
| --- | --- | --- | --- | --- |
| D1 | **风格一致性** | 前后像两个产品；卡片有三种长相 | 大体一致，个别字号/圆角不统一 | 截图排一起像同一套设计系统出品 |
| D2 | **空间与层次** | 分不清分组与内容；靠重阴影硬分层 | 层次可辨但需要盯一下 | 一眼看出"这是一组、那是单张、这是浮层" |
| D3 | **交互手感** | 拖动滞后、缩放跳变、吸附粘手 | 基本跟手，偶有顿挫 | 像在纸上移动实体，想放哪就放哪 |
| D4 | **连续流** | 一次任务要跳 3 个页面 | 能在一屏完成，但要反复开合面板 | 从头到尾没离开同一个平面 |
| D5 | **认知负荷** | 满屏都是东西，不知道先看哪 | 有点乱，但能找到重点 | 信息很多，但安静、不吵、知道从哪开始 |
| D6 | **学习闭环** | 只能记录，记完就断 | 能读能记能连，但没有"回头再看" | 采→读→抓→连→问→复都在一个空间里 |
| D7 | **可逆与安全感** | 误操作找不回，不敢乱动 | 主要操作能撤销 | 什么都敢试，一步就能退回 |
| D8 | **跨场景一致性** | 暗色像反色；空态写"暂无内容" | 暗色能用，空态有提示 | 明暗两副表情像同一个产品；空态也在引导下一步 |

### 闸门

| 节点 | 要求 |
| --- | --- |
| 每个 Stage 结束 | 平均 ≥ 3.5；无单项 < 2；**D1、D4 ≥ 3** |
| Stage 4 结束 | **D3 ≥ 4**（手感必须在这一阶段达标） |
| Stage 5 结束 | **D6 ≥ 4**（差异化必须被感知到） |
| Stage 8 总验收 | 平均 ≥ 4.0；**D1、D4、D6 ≥ 4.5**；无单项 < 3 |

> 关键三项 D1/D4/D6 对应本次任务的三个诉求：**像、顺、是学习空间**。

## 三、感知性能预算

| 场景 | 应该感觉到 | 失败线 |
| --- | --- | --- |
| 任何按钮/卡片点击 | 按下即变 | 反应晚于一次眨眼 |
| 拖动对象 | 贴着指针，无拖影无追赶 | 出现可见滞后 |
| 缩放画布 | 连续变化，不跳帧不糊 | 任一次卡顿 |
| 打开卡片 | 结构立刻出现，内容紧随 | 空白等待超过数到三 |
| 打开大板（150+ 对象） | 骨架先到，细节随后 | 白屏超过一秒 |
| AI 回答 | 1 秒左右出现并逐段流出 | 2 秒无反馈 |
| 换标签页 | 立即切换，滚动位置不丢 | 位置丢失或闪烁 |
| 撤销 | 立即回到上一状态（无过渡动画） | 需要等动画 |

**原则**：宁可少一个功能，也不要一次"卡一下"。一次卡顿会被记住一整天。

## 四、反模式清单（出现任一条即不合格）

| 反模式 | 为什么致命 |
| --- | --- |
| 用重阴影 / 渐变大色块制造层次 | 密度一高就脏；HeptaBase 的层次几乎全靠描边与留白 |
| 满屏彩色 | 颜色一旦装饰化，就失去"分类"的功能性 |
| 用抽屉 / 弹窗承载主要任务 | 主任务必须在平面内完成；弹窗只用于确认与临时选择 |
| 关键操作只在悬停时出现 | 新手与触屏都找不到；悬停只能"加速"，不能"发现" |
| 菜单套菜单超过两层 | 学习工具的用户不是工程师，深菜单等于不存在 |
| 没有撤销 | 用户退回"整齐摆放"，空间范式失效 |
| 动效 > 250ms / 大量弹跳 | 用户会关动画，然后界面变成硬切 |
| 暗色 = 反色 | 深色下阴影不可见，卡片失去层次 |
| 空态写"暂无内容" | 空态是最有价值的一屏，应给出下一步 |
| 每屏各自定义字号/圆角 | 风格漂移的起点，也是耦合的第一个信号 |

## 六、为什么这套能挡住"感觉还行"

- **可复现**：同一版本不同人跑同一组测试，结论差异 ≤ 1 分；
- **可归因**：分低能定位到维度与测试（"D3 低 → 拖动滞后"），而不是"再改改"；
- **抗漂移**：T1 与 T4 都是跨时间检查，能抓住"改着改着就不像了"；
- **对用户公平**：所有指标都问"用户能不能做成事"，不问"设计是否时髦"。
