## 0. 一句话

**卡片和分区的颜色用法做反了**——参考图是"白卡身 + 浅色标题区"，分区是"整块浅底 + 顶部全宽实色横条"；
我们做成了"整卡浅色 + 短胶囊"。这一处不改，其他细节怎么调都不像。

另外左栏有 **21 个按钮点了没有任何反应**（含 7 个应用入口），每个页面都有，所以显得"到处都点不动"。
**这一批已修**，见 §1.1。

## 1. 死按钮（已修）

### 1.1 修之前的真实情况

用 React props 逐个检查，**每个页面 21 个**，全部在左栏：

| 组 | 数量 | 表现 |
| --- | --- | --- |
| 顶部 | 3 | 新建学习主题 / `+` / 搜索 —— 点了不动 |
| 应用区 | 7 | Inbox / 今日 / 白板 / 卡片库 / 标签 / 划线 / AI 对话 —— **有 onClick，但回调是 `undefined`** |
| 标签区 | 11 | `+` 与 10 个标签 —— 点了不动 |

审计时容易误判：应用区那 7 个**有** `onClick`，只是内部 `onAppSelected?.(id)` 而调用方没传，
所以"静态检查有空函数"查不出来。要按行为测。

### 1.2 怎么修的

| 按钮 | 现在点了会 |
| --- | --- |
| 新建学习主题 / `+` | 跳到白板并**当场新建一张卡**、选中它 |
| 搜索 | 跳卡片库并**打开 ⌘O 搜索浮层** |
| Inbox / 今日 / 白板 / 卡片库 / 标签 / 划线 / AI 对话 | 各自跳对应页面；AI 对话直达右栏 AI |
| 新建标签 `+` | 跳标签库 |
| 任一标签 | 跳卡片库并**预设该标签筛选**（实测 `FSRS` → 37 张） |
| 顶栏 `+` | 新建一张卡片（进编辑态） |
| 卡片属性行 `+` | 变成输入框，回车加标签 |

改法：把所有屏各自手写的 `onAppSelected` 删掉——它们各自只覆盖 2–4 个入口，且互相不一致
（S01 把「卡片库」指到 `/s03`，S09 漏了「划线」）。统一由左栏的 `APP_ROUTE` 兜底。

### 1.3 复测

8 个页面：`button` + `[role=button]` 共 495 个，**无处理函数的 0 个**。

## 2. 视觉差异（按影响排序）

### 2.1 卡片：整卡浅色 → 应为白卡身 + 浅色标题区

| | 参考图（`reading-knowledge.png`、`whiteboard-feature.png`） | 我们（`s02-light.png`） |
| --- | --- | --- |
| 卡身 | **白色**，1px 浅灰描边 | 整卡浅绿 / 浅蓝 / 浅黄 |
| 标题区 | 卡片上部一块**浅色区**，标题字是彩色粗体 | 没有分区，整卡同色 |
| 正文 | 白底黑字，行距松 | 绿底黑字 |
| 缩略时的观感 | 一片白里点着几块淡彩 | 一片彩色块，密起来像便利贴墙 |

参考图里"Complex arguments are programmatic"那张：卡是白的，只有标题字是绿色。
"School math × math that could be taught"那张：标题在一整块浅绿上，正文白。

两张不完全一致，但**都不是"整卡一块色"**。

### 2.2 分区：短胶囊 → 应为全宽实色横条

| | 参考图 | 我们 |
| --- | --- | --- |
| 形态 | 横跨整个分区宽度、圆角 6px、高约 28px 的**实色条** | 一个短胶囊（宽度随文字） |
| 文字 | 白色粗体，右侧还有 `···` | 白色 12px，右侧只有计数 |
| 底色 | 分区内部**明显**的浅色（粉/蓝/绿，透明度很低但不至于看不见） | 几乎与画布同色，只有卡片在浮着 |
| 举例 | `Cultural issues of education` 那条红色横条 + 淡粉底 | 「为什么间隔有效」蓝色小胶囊 |

### 2.3 顶部：标签页 → 参考是面包屑 + 右侧操作组

| | 参考图 | 我们 |
| --- | --- | --- |
| 位置标识 | `Books / Mindstorms` 面包屑，带 app 切换图标 | 一排可关闭的 tab |
| 右侧 | `Share`、`···`、三个圆形图标（搜索/图层/日历） | 只有主题切换和右栏开关 |
| 我们的面包屑 | 只在**子板**里出现 | 父板没有，所以平时看不到层级 |

### 2.4 连线：有箭头 → 参考无箭头

参考图的线是纯曲线，端点直接接到卡片边缘，没有箭头。
我们画了箭头（`direction: 'one'` 会渲染三角）。

### 2.5 日志页缺三样

| 参考图（`kb-daily-journals.png`） | 我们（`s10-journal.png`） |
| --- | --- |
| 顶部周条带**内容圆点**（有内容的日子标题前有 •） | 没有圆点 |
| 周条左右 `‹ ›` + 右侧 `Today` 按钮 | 没有 |
| 标题上方有 `FRIDAY` 小字，右上角 `1 todo` 胶囊 | 只有「10 月 22 日 · 周四」 |
| 正文是**三级缩进列表**（实心点/空心圈/方块，带左侧竖线） | 两块独立的白卡，各一段话 |

### 2.6 PDF 页缺四样

| 参考图（`learning-screenshot.png`） | 我们（`s05-zoom.png`） |
| --- | --- |
| 左侧有**页码缩略图 + 大纲**，带颜色标记 | 没有 |
| 正文**两页并排** | 单页竖排 |
| 右侧是**可编辑的笔记面板**（彩色标题、项目符号、缩进） | "摘录：0"的空面板 |
| 划词后的工具条是**贴在文字旁的竖条图标** | 横排浮层 |

### 2.7 斜杠菜单：8 项一列 → 参考 24 项三列

参考图 `kb-block-editor.png` 是 3 列 × 8 行 = 24 项，每项有一个图标方块。
我们是 8 项单列，只有图标 + 文字。

### 2.8 已经对上的（不用改）

- 左栏应用区：圆形彩色图标 + 名称 + 计数徽标 ✅
- 左侧画布工具条：6 个线性图标竖排 + 底部 `···` ✅
- 右下缩放：`100%` + `−` + `+` ✅（参考在右下，我们也在右下）
- 左下缩略图 ✅
- 卡片内的行距与字号（13/1.6）✅
- 浅色底 + 1px 描边的整体调子 ✅
