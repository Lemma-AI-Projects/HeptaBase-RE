## 6. 布局算法（照抄，保证截图可复现）

```
每个分区：
  padding = 16
  colW = 240, gap = 24
  colX = [section.x + 16, section.x + 16 + 240 + 24]
  cursorY = [section.y + 16, section.y + 16]
  按数组顺序取卡：
    w = 528 → y = max(cursorY); x = section.x + 16
              cursorY = [y + h + 24, y + h + 24]
    w = 240 → 取 cursorY 较小的一列（相等取左列）
              x = colX[i]; y = cursorY[i]
              cursorY[i] = y + h + 24
  section.h = max(cursorY) - section.y + 16 - 24   // 去掉最后一个 gap
```

相邻分区若高度超出而重叠（A 底 > C 顶），把 C 的 y 下移到 A 底 + 100。这条只在改内容时用到，当前内容不触发。
