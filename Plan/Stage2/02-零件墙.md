## 0. 目录与命名

```
app/src/parts/
  C60-Button/
    C60-Button.tsx        # 组件，默认导出
    C60-Button.module.css # 只有本零件用的样式
    index.ts              # export { Button } from './C60-Button'
```

规则：
- 一个零件一个目录；**不许跨目录 import 另一个零件的内部文件**，只能 import 它的 `index.ts`。
- 零件不 import `fixtures/`、不 import `screens/`、不 import 全局 store。
- 颜色/字号/圆角一律 `var(--token)`；CSS Module 里不出现字面量色值。

## 2. 五个状态怎么落到零件墙上

零件墙是 `/lab` 一页，每个零件一行，行内并排 5 个实例。每个实例下方 11px 灰标签写状态名。

| 状态 | 判定 | 例 |
| --- | --- | --- |
| 默认 | 最小输入 | 一张只有标题的卡 |
| 悬停 | 鼠标在元素上 | 卡：`--sh-2` + 描边转 `--c-line-strong` |
| 选中 | `selected=true` | 卡：`inset 0 0 0 1.5px var(--c-accent)` |
| 禁用 | `disabled=true` | 按钮 40% 不透明 + `cursor: not-allowed` |
| 空 | 必填输入缺失（R4） | 卡：标题位显示"无标题"，高度不塌 |

「悬停」在静态截图里拍不到 → 零件墙给每个零件加 `data-force="hover"` 开关，用属性选择器把悬停样式常驻，便于截图比对。

## 3. 需要写清楚的 4 个零件

### C11 CardNode

```
输入
  card      { id, title, lines[], color, folded?, updatedAt? }   必填；title 缺 → "无标题"
  selected  boolean   默认 false
  hovered   boolean   默认 false
  readonly  boolean   默认 true（Stage 2 恒 true）
  mastery   'none' | 'fuzzy' | 'solid'   默认 'none'，Stage 2 只画 'none'
  density   'canvas' | 'grid' | 'review' 默认 'canvas'
输出
  selected, opened, colorChanged(color), folded(bool)
禁止
  ✗ 读缩放 / 视口 / 自己在板上的位置（位置由外层 transform 决定）
  ✗ 内部决定"点一下是选中还是打开"
结构
  <div class=card>
    <span class=colorBar />            ← 4px 卡头细条，只有 color ≠ 'gray' 时画
    <h3 class=title>{title}</h3>        ← 14/1.6/500，最多 2 行
    <div class=body>{lines}</div>       ← 13/1.6/400，最多 5 行，超出 line-clamp + 底部渐隐
    <span class=foldMark />             ← folded 时右下小折角，尺寸 12×12
  </div>
尺寸
  宽 240（固定，由外层给）；高由 fixture 的 h 决定，不给则 min 88
  内边距 8 12 12 8（上右下左）
  folded 时只留 40 高，只显示标题一行
```

`lines` 里允许两种极简标记，由 `lib/renderInline.ts` 渲染（只读，不解析 Markdown 全量）：
`- ` = 列表项（行首 4px 圆点，缩进 12）；`==text==` = 高亮（`background: #F5E6A8; padding: 0 1px`，暗色 `#4A3D14`）。

### C10 CanvasViewport

```
输入
  viewport   { x, y, zoom }        必填；zoom 10–400 的百分数换算成 0.1–4
  objects    { bounds: Rect[] }    仅用于计算内容外框（fit 用）
  readonly   boolean               默认 true
  children   ReactNode             画布内所有图层
输出
  viewportChanged({x,y,zoom})
  blankDoubleClicked({x,y})        空白处双击（Stage 2 只 console 占位）
实现约束
  · 根节点 position:relative; overflow:hidden，写入 --zoom
  · 内层 transform: translate3d(x,y,0) scale(zoom)，transform-origin: 0 0
  · 滚轮：默认纵向滚动；⌘/Ctrl+滚轮 = 以指针为锚点缩放；Shift+滚轮 = 横移
  · 空格按住 = 临时抓手（cursor: grab/grabbing）
  · 监听 wheel 必须 passive:false 才能阻止浏览器缩放
禁止
  ✗ 自己决定缩放上下限（由 props 传）
  ✗ 把 zoom 写进子组件 props（子组件靠 CSS 变量感知）
```

锚点缩放公式（照抄）：
```
world = (pointer - offset) / zoom
zoom' = clamp(zoom * factor, 0.1, 4)
offset' = pointer - world * zoom'
```

### C12 SectionBox

```
输入
  section   { id, title, color, x, y, w, h, count }  必填
  collapsed boolean   默认 false
  selected  boolean   默认 false
  readonly  boolean   默认 true
输出
  renamed(title)  collapsed(bool)
结构
  底色层  绝对定位，圆角 --r-1，background = color-mix(fill 68%, canvas)
  胶囊    absolute; top:-26px; left:0; height 24; padding 0 10;
          圆角 --r-full；background = solid；白字 12/1.5/500；右侧计数 "8"
  折叠    高度塌到 44，只留胶囊 + 一行 "8 张"
禁止
  ✗ 分区自己画边框（参考图没有边框，只靠底色）
  ✗ 分区自己移动内部卡片（由卡片自己定位）
```

### C15 Edge

```
输入
  edge   { id, from:{x,y,side}, to:{x,y,side}, shape:'curve'|'ortho',
           direction:'one'|'both', label?, selected? }
  from/to 是**已换算好的世界坐标锚点**（外层从卡片 rect 算，零件不算）
输出
  selected
实现
  <svg> 绝对铺满画布内层，z-index 在分区之上、卡片之下；溢出 visible
  曲线：三次贝塞尔，控制点 = 水平/垂直方向各推出 max(40, 距离*0.4)
  线宽 1，颜色 --c-line-strong（选中 --c-accent）；箭头 6×6，同色
  标签：白底 --r-1、8/2 内距、12px、居中压在路径 50% 处，距线 6
禁止
  ✗ 连线穿过卡片（路径经过卡片矩形即视为不合规，验收项）
```

### C63 Popover

```
输入
  anchor     元素引用或 Rect  必填
  open       boolean
  placement  'auto' | 'top' | 'bottom' | 'left' | 'right'   默认 'auto'
  modal      boolean  默认 false
  children
输出
  dismissed
翻转规则
  先按 placement 放；越出视口则镜像；镜像仍越界则夹到距视口边 8px
  永远不覆盖 anchor 所在矩形的中心（V10）
样式
  --c-panel 底 + --r-2 + --sh-2 + 8px 内边距 + 1px --c-line
  ESC 关闭；点击外部关闭（pointerdown 捕获阶段）
```
