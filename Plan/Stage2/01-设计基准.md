# 01 · 设计基准（V1–V13 的唯一来源）

> 这一份里的数值，是代码里**唯一允许出现**的数值。零件内部写死任何颜色/字号/圆角，即视为违约（[03-组件契约](../03-组件契约.md) R3）。
> 落地方式：`app/src/styles/tokens.css` 定义 CSS 变量，`app/src/tokens/index.ts` 导出同名字符串供 TS 使用。两份必须同名同值，改一处即改两处。

## 2. 卡片 / 分区色板（7 色）

色只出现在**卡头细条、分区胶囊、分区底色**上；卡片正文永远是 `--c-text`。

| 名称 | `fill`（卡头/浅底） | `solid`（分区胶囊/连线标签） | 暗色 `fill` |
| --- | --- | --- | --- |
| green | `#E9F0E4` | `#6F9A6A` | `#2A3527` |
| blue | `#E4EDF6` | `#5C86B8` | `#242F3B` |
| orange | `#F8ECDF` | `#C08A5A` | `#382C21` |
| purple | `#EFE9F4` | `#8B7BA8` | `#2E2939` |
| red | `#F7E5E2` | `#C07066` | `#382624` |
| yellow | `#F8F1D8` | `#C0A04A` | `#35301F` |
| gray | `#F0F0EB` | `#8C8B85` | `#2B2B27` |

派生值（用 `color-mix`，不新增常量）：

```
分区底色     = color-mix(in oklab, var(--c-<name>-fill) 68%, var(--c-canvas))
卡头细条     = var(--c-<name>-fill)          高 4px，贴卡片内上边
分区胶囊文字 = #FFFFFF   （以 references/heptabase-ui/whiteboard-feature.png 为准：实色胶囊 + 白字）
```

> 与 01 文档 V8 的偏差说明：V8 写"胶囊更浅"，参考图是**实色胶囊白字**。以图为准，V8 文字随后修订。

## 8. 动效（3 曲线 × 3 时长，V13）

| token | 值 | 用在哪 |
| --- | --- | --- |
| `--dur-1` | 120ms | 悬停、按下、描边变化 |

## 9. 描边（缩放下的 1px）

画布里的一切描边用 `box-shadow: inset 0 0 0 var(--hair)`，不用 `border`（border 会推布局，且缩放时出现半像素缝）。

```css
--zoom: 1;                                  /* 由 C10 写在画布根节点上 */
--hair: clamp(0.5px, calc(1px / var(--zoom)), 2px);
```

- 缩放 10%：描边 2px 上限，保证卡片还有边；
- 缩放 400%：描边 0.5px 下限，保证不像粗框；
- 圆角不补偿，随画布缩放（补偿会造成"圆角大小跳变"）。

## 10. 禁止清单

| 禁止 | 原因 |
| --- | --- |
| 除本文件外的字号 / 圆角 / 间距数值 | 一屏出现两套字号即不合格（Stage 2 验收项） |
| 第二个强调色（绿=对/红=错需报备） | V6 |
| 纯黑 `#000` 文字、纯白 `#FFF` 画布 | 会让卡片失去层次 |
| 彩色线性图标 | V9：图标只灰度，应用图标是唯一例外 |
| 卡片内写死颜色（`color: #333`） | R3 |
| 700 字重、字间距调整、渐变背景 | 参考图里都没有 |
