# Stage 4 · 「连 → 想」竖切片（S02 可交互）

> 交付：白板上能真的摆、连、改、撤，手感像工具而不像演示。
> 依据：[04-阶段任务与验收](../04-阶段任务与验收.md) 4.1–4.13
> 状态：拖拽 / 吸附 / 框选 / 菜单 / 工具条 / 分区 / 折叠 / 撤销 / 小地图 / 压力板 / 连线编辑已落地；面包屑、手感调优未做

---

## 1. 状态模型

```
Board = { objs: Obj[], sections: Sec[], edges: EdgeData[] }
Obj   = { id, kind: card|text|media, x, y, w, h, folded?, color?, sectionId?, … }
```

- 一切都是**绝对坐标对象**，初始位置由 Stage 2 的瀑布流算一次，之后由拖拽改写。
- 历史 = 快照栈（最多 50 步），`run(fn)` 提交前压栈；撤销/重做直接换整个快照。
- 拖拽过程中不写状态：只把 `translate3d(dx,dy)` 挂在被拖对象上，松手时一次提交。
  好处：拖动跟手（不触发 React 重排），撤销只记一步。

## 5. 没做好 / 下一步

1. **手感没有基线**：跟随系数、吸附阈值、松手回弹都还没写下来，也没做 30 秒录屏前后对比。
2. **拖拽没有边界约束**：可以把卡拖到负坐标，画布会跟着长。
3. **吸附只看对象边与中线**，等距分布提示（相邻间距相等）还没做。
4. **撤销不还原选中态**：撤销后选中集合可能指向已删除对象。
