## 三、怎么用这个库

1. **做任何视觉决定前**，先找到对应的图，而不是凭记忆描述"HeptaBase 的感觉"；
2. **每次交付前**，用 [01-范围与基准.md](../01-范围与基准.md) §7 的 13 条指纹各找一张图做并排（T1 截图指纹比对）；
3. **不追求逐像素复刻**：参考的是范式与比例，不是某个版本的像素值（HeptaBase 自身也在迭代）；
4. 如果发现某张图与最新版产品不一致，**以范式为准**，并在该行标注"版本差异"。
