## 5. 没做好

1. **回答是脚本，不是模型**：按 A3 的约定，只有一段固定回答，问题文字不影响答案。评审时要说明这点。
2. **复习进度不持久**：刷新即重置，没写 localStorage。
3. **每周回顾没做**，5.9 只完成一半。
4. **「增一减一」没有执行**：这一阶段加了路径条、掌握度、进度环三样，还没回答各自替掉了什么。
5. 键盘 `1/2` 只在翻面后可用，没做提示动画。
